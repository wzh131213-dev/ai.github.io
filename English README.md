# 🔑 Guide to Obtaining and Using a Free Google Gemini API Key

Google offers developers a generous **free API usage quota** (supporting 15 requests per minute and thousands of free calls per day—more than enough for personal development and daily use).

### 📌 Application Steps

1. **Visit Google AI Studio**
   Go to the official website: https://aistudio.google.com/

2. **Log in with your Google Account**
   Sign in using your Gmail or Google account.

3. **Create an API Key**

   * Once in the dashboard, click the **"Get API key"** button found in the left-hand menu or at the top of the page.

   * Click **"Create API key"** (you can create it within a new project or select an existing Google Cloud project).

4. **Copy the API Key**

   * The system will generate a key string starting with `AIzaSy...`.

   * Click **Copy** to save the key (please keep it secure and do not share it publicly).

5. **Enter the Key into the Tool**

   * Return to our **GamePrompt AI Studio** page.

   * Click the **"Settings / API Configuration"** button in the top-right corner.

   * Select the **🌐 Online API Generation** mode, paste the copied key into the input box, and click **Save and Apply**!

### 💡 Important Notes & Tips

* **Network Requirements**: Due to restrictions on Google services, accessing AI Studio and calling the API requires a network connection that supports Google AI services (nodes in the US, Japan, or Singapore are recommended).

* **Completely Free**: As long as you do not manually link a credit card to activate the Paid Plan, the default Gemini Free Tier will not incur any charges.

* **Privacy and Security**: The API key used in this tool is stored only in your browser's local storage (`localStorage`). All API requests communicate directly with Google's official servers and do not pass through any third-party intermediary servers.

# Meow Star Canteen: Healing Journey

> Rewrite your destiny using unique system mechanics in an endless, ever-changing world!

## Game Overview
Players step into the role of a kitten with alchemical culinary skills, adventuring through a dreamy, 2D side-scrolling forest. Navigate platforms to gather "starlight ingredients" scattered across the landscape, then use them in management mode to craft cat-themed dishes with profound healing powers. Blending the agility of action-exploration with the satisfaction of management simulation—and featuring a 16/32-bit retro pixel art style—the game offers players a peaceful, heartwarming sanctuary.

## Game Genre & Platform
2D Side-Scrolling Management Platformer

## Core Gameplay Mechanics
- **Side-Scrolling Ingredient Scavenging**: Players control a kitten, jumping and climbing through multi-layered forest levels to find rare ingredients like Golden Catnip and Moonlight Berries. Level design emphasizes rhythm over high difficulty and features dynamic weather that affects ingredient growth.
- **Alchemical Cooking Synthesis**: In the canteen's kitchen, players combine gathered raw materials using a grid-based synthesis system. Different recipes yield dishes with special buffs; for instance, "Shimmering Pudding" boosts movement speed, while "Serene Soup" attracts rare customers. - **Dynamic Canteen Management**: As your cooking level rises, the canteen will attract more stray cat NPCs. Players must serve the correct dishes to unlock the NPCs' personal stories and earn "Cat Coins," which can be used to decorate the canteen or upgrade kitchen equipment. ## Art Prompts
- **Scene/Environment Prompt**: Pixel art game background, 32-bit aesthetic, cozy forest at night, giant glowing mushrooms, floating stars, warm interior of a wooden cabin kitchen, side-scrolling layout, soft ambient lighting, pastel colors, high-resolution pixel details, Ghibli-inspired atmosphere.
- **Character/Sprite Prompt**: Character sprite sheet for a cute ginger tabby cat, 16-bit pixel art style, multiple frames of walking, jumping, sitting, and cooking animations, wearing a tiny chef hat and apron, expressive face, clear silhouettes, vibrant color palette.
- **UI Prompt**: Game UI design, 16-bit pixel art, inventory slots with wood texture, cat paw icons for buttons, fish-shaped health bar, vintage font, warm yellow and brown tones, translucent menu overlays.

## AI Programming Prompt
```
Write a complete Three.js boilerplate for a 2D side-scrolling platformer. Requirements: 1. Use OrthographicCamera for a 2D perspective. 2. Implement a 'Player' class using THREE.Sprite or THREE.Mesh with a plane geometry for pixel art textures. 3. Include a gravity-based physics engine with jumping and collision detection for platform objects. 4. Create a 'GameStates' object to handle switching between 'Exploration' (side-scroller) and 'Cooking' (UI-based synthesis) modes. 5. Set up an animation loop using requestAnimationFrame with delta time for smooth movement. 6. Handle WASD/Arrow keys for movement and 'E' for interaction. 7. ```
```

## World-building & Story
In the distant "Forest of Floating Light," legend has it that whenever a shooting star streaks across the sky, it carries away the weariness of a soul. The protagonist, "Nuomi," is a cat who has mastered ancient culinary arts and has set up a late-night diner deep within the forest. The guests here are not merely animals, but also fleeting spirits seeking a brief escape from the bustling world. By running the canteen, players do more than just cook; they weave a tale of companionship and belonging. Late at night, amidst the flickering lights and the steam rising from hot soup, one finds a truly healing moment.
